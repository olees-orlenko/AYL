# Мобильное приложение «АЮЛ» (iOS)

Современное мобильное приложение для участников и руководителей организации, объединяющее в себе информационную ленту, галерею мероприятий, контакты и базу данных штата. Приложение интегрировано с Firebase и поддерживает полноценную систему администрирования.

 ## 📱 Основные возможности

 ### Для пользователей:
* Новости: Актуальная лента событий с возможностью перехода к полным статьям и внешним ссылкам.
* Галерея: Разделенная по категориям фотогалерея мероприятий с поддержкой полноэкранного просмотра и кэширования изображений.
* Штат: Список команды с детальной информацией, описанием и быстрыми ссылками на социальные сети (Telegram).
* Контакты: Интерактивные ссылки на сайт, социальные сети и карту региональных отделений.
* Адаптивный дизайн: Полноценная поддержка Темной и Светлой тем оформления.

 ### Для администраторов (Admin Panel):
* Авторизация: Защищенный вход через Firebase Auth.
* Управление контентом: Добавление, редактирование и удаление новостей, фотографий и карточек сотрудников прямо в приложении.
* Работа с медиа: Управление изображениями через прямые URL-ссылки с мгновенным предпросмотром.
* Синхронизация: Все изменения мгновенно отображаются у пользователей благодаря Firestore.

 ## 🛠 Технологический стек

* Язык интерфейса: Swift (SwiftUI).
* Архитектура: MVVM (Model-View-ViewModel).
* Backend:
  * Firebase Firestore (база данных реального времени).
  * Firebase Authentication (безопасный вход).
* Библиотеки: 
    * Kingfisher — высокоэффективная загрузка и кэширование изображений.
    * WebKit — отображение внутренних веб-страниц.

 ## 🏗 Установка и запуск

### Для запуска iOS-версии проекта локально:

1.  Клонируйте репозиторий:
git clone git@github.com:olees-orlenko/AYL.git
2.  Настройте Firebase:
    * Создайте проект в Firebase Console.
    * Добавьте iOS-приложение и скачайте файл GoogleService-Info.plist.
    * Добавьте GoogleService-Info.plist в корень проекта Xcode.
3.  Установите зависимости:
    Проект использует Swift Package Manager. Зависимости (Kingfisher, Firebase) подгрузятся автоматически при открытии .xcodeproj файла.
4.  Запустите проект:
    Выберите целевое устройство (симулятор или iPhone) и нажмите Cmd + R.

 ## ⚙️ Требования
