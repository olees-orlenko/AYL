# Мобильное приложение «АЮЛ» (iOS)
Современное мобильное приложение для участников и руководителей организации, объединяющее в себе информационную ленту, галерею мероприятий, контакты, базу данных штата и личный кабинет участника с квизами и сертификатами. Приложение интегрировано с Firebase и поддерживает полноценную систему администрирования.

## 📱 Основные возможности

### Для пользователей:
* Новости: Актуальная лента событий с возможностью перехода к полным статьям и внешним ссылкам.
* Галерея: Разделенная по категориям фотогалерея мероприятий с поддержкой полноэкранного просмотра и кэширования изображений.
* Штат: Список команды с детальной информацией, описанием и быстрыми ссылками на социальные сети (Telegram).
* Контакты: Интерактивные ссылки на сайт, социальные сети и карту региональных отделений; в личном кабинете участники могут запрашивать контакты друг у друга, а получатель подтверждает запрос, после чего контакт становится виден в профиле.
* Личный кабинет: регистрация и вход участника, публичный профиль с историей участия в мероприятиях и значками достижений.
* Квиз: прохождение серии вопросов с подсчётом результата и рейтинг (лидерборд) среди участников.
* Сертификаты: автоматическая генерация именного сертификата участника после завершения мероприятия и одобрения заявки администратором, с возможностью поделиться сертификатом.
* Адаптивный дизайн: полноценная поддержка Тёмной и Светлой тем оформления, включая тематические фоновые изображения для экранов квиза.

### Для администраторов (Admin Panel):
* Авторизация: Защищённый вход через Firebase Auth.
* Управление контентом: Добавление, редактирование и удаление новостей, фотографий и карточек сотрудников прямо в приложении.
* Управление квизом: Добавление, редактирование и удаление вопросов квиза.
* Заявки на сертификаты: Просмотр заявок участников с указанием мероприятия, одобрение или отклонение выдачи сертификата.
* Работа с медиа: Управление изображениями через прямые URL-ссылки с мгновенным предпросмотром.
* Синхронизация: Изменения отображаются у пользователей через Firestore.

## 🛠 Технологический стек
* Язык интерфейса: Swift (SwiftUI).
* Архитектура: MVVM (Model-View-ViewModel).
* Backend:
  * Firebase Firestore (база данных; для большинства экранов используются разовые чтения вместо постоянных слушателей — данные обновляются при открытии экрана и по свайпу «потянуть, чтобы обновить», что снижает нагрузку и стоимость на Firestore).
  * Firebase Authentication (вход администратора и личный кабинет участников).
* Генерация сертификатов: Core Graphics / UIGraphicsImageRenderer — сертификат с именем участника и названием мероприятия собирается прямо на устройстве поверх единого шаблона.
* Библиотеки:
    * Kingfisher — высокоэффективная загрузка и кэширование изображений.
    * WebKit — отображение внутренних веб-страниц.

## 🏗 Установка и запуск
### Для запуска iOS-версии проекта локально:
1.  Клонируйте репозиторий:
git clone git@github.com:olees-orlenko/AYL.git
2.  Настройте Firebase:
    * Создайте проект в Firebase Console.
    * Добавьте iOS-приложение и скачайте файл GoogleService-Info.plist.
    * Добавьте GoogleService-Info.plist в корень проекта Xcode.
3.  Установите зависимости:
    Проект использует Swift Package Manager. Зависимости (Kingfisher, Firebase) подгрузятся автоматически при открытии .xcodeproj файла.
4.  Запустите проект:
    Выберите целевое устройство (симулятор или iPhone) и нажмите Cmd + R.
